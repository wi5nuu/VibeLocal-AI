# VibeLocal – Emergency AI Assistant for Indonesians

A modern, production-ready web application with Silicon Valley-grade design.

## Features

- **Landing Page** - Hero section, Problem/Solution showcase, Features, Interactive Demo
- **Main App** - Split-screen dashboard for emergency analysis
- **Modern UI** - Inspired by Vercel, Linear, and Apple Design
- **Animations** - Smooth Framer Motion transitions
- **Dark Mode** - Full dark/light theme support

## Tech Stack

- Next.js 14 (App Router)
- React + TypeScript
- TailwindCSS
- Framer Motion
- Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## Pages

- `/` - Landing page with all marketing sections
- `/app` - Main emergency assistant dashboard
